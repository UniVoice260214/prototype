# 실제 모바일·태블릿 통합 테스트 체크리스트

## 권장 테스트 조합

- 교수: Android Chrome 최신 버전
- 교수: iPhone Safari 최신 버전
- 학생: Android 태블릿 Chrome
- 학생: iPad Safari
- 최소 1회는 교수 1명과 학생 2명 이상 동시 접속

각 테스트는 기기, OS, 브라우저 버전, 네트워크, 결과와 재현 절차를
기록한다.

## 사전 확인

- [ ] `/health/live`가 200을 반환한다.
- [ ] `/health/ready`가 200을 반환한다.
- [ ] Caddy 또는 Tailscale Serve 인증서가 브라우저에서 신뢰된다.
- [ ] 브라우저 콘솔에 mixed-content 오류가 없다.
- [ ] AI Worker 로그에 Redis 구독 시작이 표시된다.
- [ ] LiveKit URL이 `wss://`를 사용한다.
- [ ] 업로드된 강의자료의 HTTPS Blob URL이 실제 기기에서 200으로 열린다.

## 교수 모바일

- [ ] 교수 계정으로 로그인할 수 있다.
- [ ] 담당 과목이 실제 API 데이터로 표시된다.
- [ ] 복수 번역 언어를 선택하고 수업을 시작할 수 있다.
- [ ] 최초 마이크 권한 요청이 표시된다.
- [ ] 권한 허용 후 교수 오디오 트랙이 publish된다.
- [ ] Worker 상태가 `starting`에서 `ready`로 바뀐다.
- [ ] 마이크 PAUSED/ON 전환이 실제 publish 상태와 일치한다.
- [ ] QR 모달과 입장 링크 복사가 동작한다.

## 학생 태블릿

- [ ] QR 스캔 후 `/join?token=...`이 열린다.
- [ ] JoinToken에서 올바른 session이 식별된다.
- [ ] 지원되는 번역 언어를 선택할 수 있다.
- [ ] 선택 언어의 `caption.final`만 화면에 표시된다.
- [ ] 한국어 `sourceKo`와 번역문이 함께 표시된다.
- [ ] `tts.{locale}` 오디오가 재생된다.
- [ ] autoplay가 차단될 때 사용자 안내가 표시된다.
- [ ] 강의실 나가기가 오디오와 LiveKit 연결을 정리한다.

## 네트워크와 새로고침 복구

- [ ] 교수 화면 새로고침 후 기존 활성 세션이 복구된다.
- [ ] 교수 토큰이 재발급되고 마이크 권한을 다시 요청한다.
- [ ] 경과 시간이 `startedAt` 기준으로 이어진다.
- [ ] QR과 Worker polling이 다시 시작된다.
- [ ] Wi-Fi를 10초 끊었을 때 `재연결 중`이 표시된다.
- [ ] 네트워크 복구 후 `다시 연결됨`과 `수업 진행 중`이 표시된다.
- [ ] PAUSED 상태에서 네트워크를 복구해도 마이크가 자동으로 켜지지 않는다.
- [ ] 교수 오디오 트랙 재발행 후 Worker가 새 트랙에 다시 attach한다.
- [ ] 학생도 네트워크 복구 후 자막과 TTS를 다시 수신한다.

## 동시 접속과 장시간 실행

- [ ] 학생 2명 이상이 서로 다른 언어로 동시에 참여한다.
- [ ] 언어별 자막이 섞이지 않는다.
- [ ] 언어별 TTS 트랙이 겹치거나 순서가 바뀌지 않는다.
- [ ] 30분 이상 실행해도 Worker 메모리와 지연이 급격히 증가하지 않는다.
- [ ] 동일 segment의 `segmentId`와 `sequence`가 STT/caption/audio에서 일치한다.

## 종료

- [ ] 종료 버튼을 연속으로 눌러도 요청이 한 번만 처리된다.
- [ ] Worker 상태가 `stopping`, `stopped` 순으로 전환된다.
- [ ] 학생 자막과 음성이 종료된다.
- [ ] LiveKit Room이 삭제된다.
- [ ] Redis session/worker key가 정리된다.
- [ ] 교수 화면이 수업 준비 화면으로 돌아간다.
- [ ] 새로고침해도 종료된 세션을 복구하지 않는다.
